# Начало

Привет! Этот гайд создан для тех, кто хочет узнать основы записи клипов конкретно по CS:GO.

Здесь собрана вся основная информация по записи, решейду, пресетах и конфигам. Попытался сделать всё без лишней воды — туториал от установки программ до выведения классной картинки, следуй по порядку и не запутаешься.

{% hint style="info" %}
Если по мере гайда возникут проблемы, сначало посмотрите в топик ["Решение проблем"](reshenie-problem.md), возможно там уже есть решение!
{% endhint %}

{% hint style="danger" %}
Valve официально закрыли серверы CS:GO, но встроенный античит VAC в игре всё еще работает на защищенных серверах.\
\
Поскольку HLAE вмешивается в процесс игры, система видит его как обычный чит, не советую заходить на пользовательские сервера, есть риск на VAC. Настоятельно рекомендую использовать все показанные в гайде программы на твинк-аккаунте во избежании блокировки, спасибо.\
\
**Всё на ваш страх и риск!**
{% endhint %}
