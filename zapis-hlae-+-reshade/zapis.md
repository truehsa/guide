# Запись

## Конфиг

### Установка

Для записи используются внутренние команды HLAE в консоли CS:GO, чтобы постоянно их не вписывать и легко ориентироваться при записи с помощью конфига:

{% file src="../.gitbook/assets/adamRESHADEunner.cfg" %}

Файл должен лежать в корневой папке игры `/csgo_legacy/csgo/cfg/` и быть активирован через консоль `exec adamRESHADEunner`

### Настройка конфига

Открываете конфиг с помощью блокнота или другого редактора текста, нам надо поменять несколько значений по вашему вкусу:

<figure><img src="../.gitbook/assets/изображение (67).png" alt=""><figcaption></figcaption></figure>

`host_framerate` отвечает за количество фпс при записи (чем оно больше, тем моушн блюр будет более гладким и мыльным); дефолтное значение - 1200.

<div align="left"><figure><img src="../.gitbook/assets/изображение (68).png" alt=""><figcaption></figcaption></figure></div>

**`mirv_streams settings edit blur exposure`**

Регулирует интенсивность моушн блюра.

* `0.1` — минимальный, едва заметный эффект.
* `1.0` — максимальное стандартное размытие.
* Можно использовать точные значения (например, `0.425`) или выходить за рамки лимита (`2.5`, `3.0`, `5.0`), если нужен экстремальный эффект. Дефолтное значение - 0.6

**`mirv_streams settings edit blur fps`**\
\
Задает итоговую частоту кадров готового видеофайла.

* Рекомендуется выставлять **от 60 до 300 FPS**, чтобы клип можно было плавно замедлять при монтаже.
* Чем выше этот параметр, тем слабее становится эффект моушн блюра. Ищите баланс под свои задачи. Дефолтное значение - 120.

**`mirv_streams record name "E:\ffmpeg"`**\
\
Укажите точный путь к папке на вашем компьютере, куда будут сохраняться записанные файлы.

* **Применение настроек:**\
  Каждый раз после изменения и сохранения конфига обязательно обновляйте его в игре:\
  `exec adamRESHADEunner`

### Бинды & Алиасы

Чтобы узнать все бинды и алиасы в конфиге, можете написать в консоли commands.

**Напишу основные**:\
\
**буква "O" ("Щ")** — начать/закончить запись;\
**hud** — включить/выключить hud (кроме киллфида и прицела);\
**radar** — включить/выключить радар;\
**chat** — включить/выключить чат;\
**noflash** — убрать ослепление от флешки.

## Запись&#x20;

1. Заходите на любую демку, для меня это будет [роут unner'a c демопака карты Guard](https://www.youtube.com/watch?v=Ux2QNQie-38).
2. Выбираете любой понравившийся пресет в решейде.
3. Переходим к нужному тику через `demo_goto <tick>`
4. Нажимаете "O" и начинается запись в замедленном времени. Не пугайтесь резких звуков, на аудио-дорожке всё будет нормально.
5. После того как клип сделан, нажимаете "O" для остановки записи и смотрите в консоль, если всё успешно, должно быть написано примерно такое:\
   \
   <kbd>Starting recording ... done.</kbd>\ <kbd>Recording to "C:\hlae\_cuts\take0006".</kbd>\ <kbd>Finishing recording ... done.</kbd>&#x20;
6.  Заходите в папку куда поставили путь для сохранения видео. Если всё правильно, то будут лежать папка `rec` с .mp4 видео и audio.wav с отдельной аудио-дорожкой.<br>
