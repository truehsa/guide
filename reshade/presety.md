# Пресеты

Как уже было сказано, решейд работает на основе пресетов. **Пресет**  — набор настроек шейдеров и текстур для выведения красивой картинки.

Паки пресетов можно спокойно находить в интернете или даже делать их самому, на самом деле в этом нет ничего сложного. Для вас подготовлен архив с пресетами, шейдерами и текстурами из видосов великого человека — [unner](https://www.youtube.com/@unner/videos).

{% hint style="danger" icon="heart" %}
Большая благодарность ему за предоставленный рабочий пак решейда, шейдеров и пресетов ко всему этому. Без него бы этого гайда не существовало!
{% endhint %}
